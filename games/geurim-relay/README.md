# 그림 릴레이

공용 미니게임의 닉네임·PIN으로 참여하는 비동기 그림 퀴즈입니다.

- 정답을 먼저 맞히면 다음 출제자가 됩니다. 그림은 서버에 남아 나중에 접속한 친구도 풀 수 있습니다.
- 정답마다 5점이며, 모든 방의 점수를 아이디별로 합산합니다. 대기방에서 전체 순위를 확인하고, 1~3위는 금·은·동 색상으로 표시합니다.
- 공용 계정 이름을 한글 2~10자의 실명으로 설정하고 참여합니다. 실명은 참가자가 직접 입력합니다.
- 계정마다 방을 하나 만들 수 있습니다. 방 제목은 1~40자이며, 운영자인 우상호 계정만 방을 삭제할 수 있습니다. 삭제 후에도 누적 점수는 유지합니다.
- 빨강·주황·노랑·초록·파랑·남색·보라·검정 펜과 지우개를 지원하며, 오답은 같은 방 참가자들에게 보입니다.
- 참여한 방은 `MiniHub.save`로 저장합니다. 같은 공용 계정이면 다른 기기에서도 최근 방에서 이어갈 수 있습니다.
- 아직 올리지 않은 그림의 임시 초안은 그 기기에만 보관합니다.

## 실행

`minigames` 전체를 Live Server로 열고 `/games/geurim-relay/`에 접속합니다.
게임 화면, 로그인, 랭킹, 진행 저장은 공용 사이트를 사용합니다.
방·그림·정답 통신만 기존 그림 릴레이 서버(`https://geurim-relay.earthy-chick-9380.chatgpt.site/api`)에 연결합니다.
서버는 공용 사이트와 localhost의 요청만 허용하며, 공용 Supabase를 통신용으로 사용하지 않습니다.
이 폴더에는 서버 비밀키가 없습니다.
